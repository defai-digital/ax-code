# AX Code 7.15.1 本地修复汇总

基于官方 `v7.15.1`（`c29ca5998fa754eed648d5981a04c368e31333e8`），发布分支为 `local/v7.15.1-all-local-fixes-20260910`。本分支收录当前本地程序相对官方版本的所有源码修改、回归测试、构建辅助脚本及修复报告。

## 修改内容

- 同一工作树内串行执行撤销、恢复及清理，防止文件与会话状态交错。
- 进程通信输出结束或关闭时及时终止等待。
- 按页找回撤销边界及上一条用户消息，保留加载后的历史窗口；提供 `/undo-history` 和 `/restore-all`，并保护取消、超时及导航后的旧请求。
- 修正未知撤销边界下的消息显示和 Undo/Redo 选择，恢复后重新采用正常历史容量限制。
- 修复恢复确认弹窗与输入框争用 Enter，以及初始化时自动历史恢复的时序问题。
- 完整会话快照清除 JSON 中已省略的旧字段，避免 Revert 后发送新消息仍保留撤销标记；边界缺失时重新确认服务端会话状态。
- 保留原有对象引用复用的渲染优化。官方 7.15.1 已包含的 Redo 文件修复和路径保护直接继承。

## 验证与本地安装对应关系

最近一次相关回归共 **89 项通过、0 失败**；类型、格式及差异空白检查通过。完整候选程序及已安装程序均通过隔离 Git/SQLite 的 350 条历史、四页加载、部分/全部恢复、中文文件与 CRLF、增删改文件、手动文件保留及撤销后新消息提交验证。新消息测试使用真实 `SessionPrompt.prompt(noReply:true)`，不调用外部模型。
