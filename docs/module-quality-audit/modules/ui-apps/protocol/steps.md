## Step 3 Bootstrap and state-transition correctness

Initialization begins immediately and retries once per second only while the store remains uninitialized, stopping after ten attempts and clearing the interval on unmount at `desktop/packages/ui/src/apps/ElectronMiniChatApp.tsx:66-89`; the underlying store coalesces overlapping calls with `_initializeAppInFlight` at `desktop/packages/ui/src/stores/useConfigStore-impl.ts:1804-1852`. Session mode first aligns the directory once at `desktop/packages/ui/src/apps/ElectronMiniChatApp.tsx:91-102`, then waits until the requested session exists before selecting it and refuses to overwrite a later user selection at lines 116-134. Draft mode aligns an opened draft's directory at lines 104-108 and creates the draft only when neither a draft nor a session is active at lines 136-143. The unavailable timer is cancelled or reset as soon as the requested session appears or becomes current at lines 224-243. These guards give the asynchronous session catalog time to hydrate without replacing deliberate user navigation.

## Step 4 Concurrency, cleanup, and cost

Worktree discovery fans out across the current project list with `Promise.all`, normalizes paths, ignores non-repositories, and suppresses stale commits through a cancellation flag at `desktop/packages/ui/src/apps/ElectronMiniChatApp.tsx:145-184`. The work itself is not abortable, so a rapidly replaced project list can leave obsolete filesystem checks running, but state writes are protected. Presence publishes immediately, every five seconds, and on unload/cleanup; its interval, event listener, and channel are all released at lines 189-219. The receiver refreshes a 15-second expiry for external views at `desktop/packages/ui/src/sync/sync-context-impl.tsx:307-355`. A Low edge remains when two windows view the same directory/session: cleanup from either publisher sends `viewed:false`, which deletes the single shared key immediately, so the still-open window may be treated as absent until its next heartbeat. The following heartbeat also calls `markSessionViewed` through `desktop/packages/ui/src/apps/AppEffects.tsx:40-44`, bounding the visible inconsistency, but publisher identity or reference counting would remove the race.

The mini-chat deliberately mounts only the runtime subset at `desktop/packages/ui/src/apps/ElectronMiniChatApp.tsx:278-287`, avoiding main-window shortcuts and overlay effects. The division follows lifecycle ownership, although `ElectronMiniChatApp.tsx` remains a broad orchestrator for configuration, directory/session bootstrap, worktree discovery, presence, and unavailable-state timing.
