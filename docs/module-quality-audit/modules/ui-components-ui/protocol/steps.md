## Step 3 State and correctness invariants

Several edge cases deserve follow-up. Concurrent calls to `requestConfirm` overwrite the single request slot at `desktop/packages/ui/src/components/ui/ConfirmDialog.tsx:35-46`, leaving the earlier promise unsettled. `desktop/packages/ui/src/components/ui/JsonTreeView.tsx:25-39` parses valid JSON `null`, but lines 62-64 then treat that value as absence and render nothing. About’s desktop-version request has no cancellation guard at `desktop/packages/ui/src/components/ui/AboutDialog.tsx:58-82`, unlike the CLI-version request at lines 87-108, so a slow response can update state after a close/reopen cycle. Finally, scrollbar metrics use a track shortened by 16px at `desktop/packages/ui/src/components/ui/OverlayScrollbar.tsx:66-89`, whereas drag conversion uses the full client dimension at lines 300-316; this under-ranges pointer dragging and can prevent reaching the scroll endpoint.

## Step 4 Performance and resource lifetime

The larger components include sensible controls: CodeMirror caches total search matches against query and document identity at `desktop/packages/ui/src/components/ui/CodeMirrorEditor.tsx:66-88`, JSON rendering switches to virtualization above 200 rows at `desktop/packages/ui/src/components/ui/JsonTreeViewer.tsx:166-200`, and file search ignores cancelled asynchronous results at `desktop/packages/ui/src/components/ui/CommandPalette.tsx:395-428`. Scrollbar observers, listeners, timers, and animation frames are released at `desktop/packages/ui/src/components/ui/OverlayScrollbar.tsx:226-242`. The remaining cost to watch is `desktop/packages/ui/src/components/ui/MemoryDebugPanel.tsx:123-131`, which polls streaming metrics every 500ms even while the memory tab is active; it is bounded by mount lifetime but could be conditional on the streaming tab.

## Step 5 Component ownership and design
