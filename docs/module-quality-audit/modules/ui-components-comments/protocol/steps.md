## Step 2 Trust and failure boundaries

Persisted browser state is the important malformed-input boundary. Hydration accepts every non-empty draft ID at `desktop/packages/ui/src/stores/useInlineCommentDraftStore.ts:91-105,251-263`, `toPierreAnnotationId` copies that ID verbatim at `desktop/packages/ui/src/components/comments/PierreDiffCommentUtils.ts:8-17`, and the overlay interpolates it into `querySelector` at `desktop/packages/ui/src/components/comments/PierreDiffCommentOverlays.tsx:66-83`. A corrupted or manually altered local-storage ID containing selector syntax can therefore throw a DOM exception and disrupt the diff view. This is a Low local robustness issue; escaping with `CSS.escape` or constraining hydrated IDs would close it.
