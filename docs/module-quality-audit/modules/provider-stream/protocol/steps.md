Attachment handling is bounded to user messages and only rewrites file/image parts (`packages/ax-code/src/provider/transform.ts:174-228`); unsupported recognized modalities become explicit error text at lines 216-224 rather than being sent to a model that cannot consume them. ## Step 3 Message and schema correctness

Message normalization has explicit provider behavior. An interleaved reasoning field or the Groq OpenAI-compatible denylist activates stripping (`packages/ax-code/src/provider/transform.ts:82-110` and `:161-172`); assistant reasoning text is collected in one part pass, non-reasoning parts retain order, and declared interleaved text is preserved under `providerOptions.openaiCompatible[field]` (`transform.ts:112-158`). Other compatible providers retain reasoning parts, avoiding a broad quality regression. Gemini schema conversion clones recursively, stringifies enum values, promotes numeric enum types after traversal, filters invalid `required` names, fills schema-empty array items, preserves combiner nodes, removes object-only keywords from scalar nodes, and terminates cycles through a `WeakSet` (`transform.ts:693-788`). Focused tests pin combiner preservation and cyclic termination at `packages/ax-code/test/provider/transform.test.ts:339-436` and `:549-568`.

## Step 4 Provider options and output budgets

Effort variants are gated first by CLI support and reasoning capability, then by known model/provider contracts (`packages/ax-code/src/provider/transform.ts:355-479`). Groq and OpenRouter reject synthesized generic efforts at lines 374-390, while Google, Anthropic, OpenAI/Meta, and supported xAI models receive provider-specific shapes at lines 392-476. Base options are merged with model, agent, selected variant, and reasoning-policy values before sanitization (`packages/ax-code/src/session/llm-impl.ts:241-260`), so explicit later configuration participates in a defined precedence chain. Alibaba sanitization removes incompatible reasoning shapes, respects an explicit `enable_thinking: false`, clamps and floors the budget, and carries `preserve_thinking` only while thinking remains enabled (`transform.ts:582-615`). Output reservation limits honor lower model ceilings and apply separate Alibaba, Groq, Qwen 3.7, and GLM caps (`transform.ts:667-690`); the focused cap cases are exercised at `packages/ax-code/test/provider/transform.test.ts:1746-1912`.

This keeps cost/accounting provenance separate from numerical normalization.

## Step 6 Hot-path and allocation review

Both candidate files are synchronous and contain no waits or external calls. Attachment compatibility maps messages and user parts (`packages/ax-code/src/provider/transform.ts:174-228`), while reasoning normalization performs a second message traversal only when stripping is required and uses one pass over each affected assistant part list (`transform.ts:109-158`). Data-URL header detection uses `indexOf`/bounded slices rather than a payload-wide capture (`transform.ts:181-203`), which is important for multi-megabyte images. Schema sanitization is linear in the reachable schema graph and removes nodes from the active `WeakSet` in `finally` blocks (`transform.ts:720-783`); upstream schema results are cached and coalesced at `packages/ax-code/src/session/prompt-tools.ts:68-92`. No unbounded retained collection is introduced by either candidate file.
