## Step 3 Read and List Correctness

Read distinguishes missing paths, directories, attachments, binary data, and streamed text. Directory offsets are one-based and reject only genuinely out-of-range pages (`packages/ax-code/src/tool/read.ts:149-194`); text offsets and per-line truncation are applied while streaming (`packages/ax-code/src/tool/read.ts:241-279`), with byte/line continuation metadata computed at `packages/ax-code/src/tool/read.ts:293-305`. File descriptors are closed in the binary sampler's `finally` block (`packages/ax-code/src/tool/read.ts:378-396`). List checks abort between directories and entries, sorts each directory's children, and stops at 100 accepted entries (`packages/ax-code/src/tool/ls.ts:64-96`). One non-gating behavior gap remains: a built-in rule such as `node_modules/` matches only a root-relative subtree at `packages/ax-code/src/tool/ls.ts:51-61`, so nested `src/node_modules` can still be traversed; the current test covers only a root-level ignored directory (`packages/ax-code/test/tool/ls.test.ts:80-98`).

## Step 4 Search Backend Parity
