## Step 2 Data and trust boundaries

Outside-workspace reads are enabled only for the editor-only context path at `FilesView-impl.tsx:1639-1641`, while edits are denied for those files and for oversized content at `FilesView-impl.tsx:2140-2145`. ## Step 3 Mutation and state correctness

Inline diff comments are not consumed before delivery: the handler snapshots current drafts, blocks duplicate awaits with a ref, clears only after `sendMessage` succeeds, and preserves drafts on failure at `desktop/packages/ui/src/components/views/DiffCommentSummaryBar.tsx:29-60`. File saves preserve the detected line-ending convention and update the in-memory baseline only after a successful write at `desktop/packages/ui/src/components/views/FilesView-impl.tsx:1456-1490`; asynchronous file loads use a monotonically increasing load id and verify the selected path before committing data at `FilesView-impl.tsx:1598-1668`. Large files cannot enter edit mode (`FilesView-impl.tsx:2140-2146`), preventing the 200,000-character display truncation from being written back. Go-to-line preview also restores the original selection on cancellation and commits only on submit at `desktop/packages/ui/src/components/views/GoToLineDialog.tsx:88-136`.

## Step 4 Concurrency and lifecycle

The unmount effect disconnects the stream at `TerminalView.tsx:280-293`, while in-flight PTY creation checks cancellation and current tab identity at `TerminalView.tsx:499-640`. ## Step 5 Performance and bounded work
