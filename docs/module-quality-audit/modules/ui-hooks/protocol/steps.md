## Step 3 State and Async Correctness

Directory selection is deterministic: an attached worktree wins, then stored worktree metadata, then the session/draft/global fallback (`desktop/packages/ui/src/hooks/useEffectiveDirectory.ts:29-50`); chat search adds the active-project fallback before the global directory (`desktop/packages/ui/src/hooks/useChatSearchDirectory.ts:23-53`). Worktree detection clears stale state and suppresses late completion after dependency changes (`desktop/packages/ui/src/hooks/useDetectedWorktreeRoot.ts:49-63,69-115`). Queue delivery requires a `busy`/`retry` to `idle` edge and explicitly targets the queued session (`desktop/packages/ui/src/hooks/useQueuedMessageAutoSend.ts:109-114,163-179`). One non-Critical robustness concern remains: the detached async worktree probe awaits command execution without a rejection handler at `desktop/packages/ui/src/hooks/useDetectedWorktreeRoot.ts:64-68`, while its helper can throw on transport or non-OK responses at `desktop/packages/ui/src/lib/execCommands.ts:31-39`.

## Step 4 Rendering and Runtime Cost

Assistant status subscribes only to the last assistant part set and encodes a scalar signature, avoiding rerenders from old part deltas (`desktop/packages/ui/src/hooks/useAssistantStatus.ts:271-289`). Model favorites and recents are memoized and hidden entries are filtered before return (`desktop/packages/ui/src/hooks/useModelLists.ts:19-56`). Auto-follow prevents parallel follow loops, cancels animation frames, and uses a bounded settle burst (`desktop/packages/ui/src/hooks/useChatAutoFollow.ts:179-234,249-277`). Its per-message handler map is intentionally stable but grows for the lifetime of the mounted hook (`desktop/packages/ui/src/hooks/useChatAutoFollow.ts:593-620`), a low-priority long-session memory consideration rather than a Critical fault.

## Step 5 Ownership and API Design

The small hooks generally preserve layer boundaries: `useAxCodeReadiness` derives presentation state from configuration (`desktop/packages/ui/src/hooks/useAxCodeReadiness.ts:3-14`), `useProjectKnowledge` reads through runtime APIs rather than a platform implementation (`desktop/packages/ui/src/hooks/useProjectKnowledge.ts:23-67`), and filesystem access delegates to the desktop abstraction (`desktop/packages/ui/src/hooks/useFileSystemAccess.ts:1-39`). `useEffectiveDirectory` and `useChatSearchDirectory` deliberately share precedence logic but are not identical because search includes project fallback (`desktop/packages/ui/src/hooks/useEffectiveDirectory.ts:29-50`; `desktop/packages/ui/src/hooks/useChatSearchDirectory.ts:42-53`). The large keyboard and auto-follow hooks remain cohesive around one interaction domain, though their size increases regression cost.

## Step 6 Cleanup, Error Handling, and Code Health
