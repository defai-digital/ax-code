Delegate a bounded, complex task to one specialist. Handle a known-file read, exact-symbol lookup or simple count directly with the relevant tool.

Available agent types:
{agents}

Specify subagent_type. Use explore for repository code and scout for upstream documentation or installed dependency behavior. For a requested custom slash command, pass the complete slash invocation as the prompt.

Give the child its question, owned paths or subsystem, relevant evidence already collected, constraints, and expected result. It cannot see this chat. Specify read-only versus implementation work and required verification. Start with one investigator for one call path; do not send multiple agents to rediscover the same files. Explicit independent review can revisit evidence, but give it a distinct verification question.

Use task_parallel only for independent read-only tasks with distinct deliverables and non-overlapping discovery scopes. Do not run concurrent writers. Do not duplicate a child's exploration while it runs. Preserve permissions and verify consequential conclusions against current source and executed checks.

Foreground is the default and waits for the final result. Set background=true only when useful independent work can continue. It returns task_id and running state; completion is delivered automatically. Do not sleep, poll, or ask for status. If the result is needed now, use waitfor.

Resume with task_id to retain the child's context instead of starting discovery again. A new invocation without task_id starts fresh. Summarize relevant findings for the user; the child's final message is not directly visible to them. Stop once the assigned question is resolved and disclose unresolved evidence.
