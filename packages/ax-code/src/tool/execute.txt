Run a bounded JavaScript subset to compose the available tools: await tools.read({filePath: "README.md"}).
Returns JSON for the final expression or return value, with execution counters. Each tool call retains its own normal permissions, hooks, isolation and output truncation. Reads may overlap with Promise.all; mutations are ordered.
Supports plain data, variables/destructuring, arithmetic, templates, conditions, loops, closures, await, try/catch/finally, arrays/strings, Map/Set, JSON, Object, Math and primitive conversions. Curated methods only; no host objects, imports, filesystem, network, eval, classes, generators, RegExp or prototype access. Functions and unawaited promises cannot be returned as JSON. Object coercion and full JavaScript compatibility are not supported.
Hard ceilings: 30 seconds, 200 tool calls, 1,000,000 steps, 1 MiB result/source/strings, AST depth 100, call depth 64, 100,000 collection entries and 4,000,000 cumulative allocation units. Config may lower them. Diagnostics include limit or source location. A failed script does not undo completed tool effects.
This is a language interpreter, not an OS sandbox for the underlying tools or plugins. Cancellation is cooperative for dispatched tools; already completed effects remain. Allocation units are a conservative interpreter budget, not a process RSS limit. Limit diagnostics use a small fixed envelope even if a configured output cap is smaller than that envelope. No Math.random, regex, sparse-array hole semantics, implicit object coercion, Promise constructors/then/catch, or full ECMAScript compatibility.
