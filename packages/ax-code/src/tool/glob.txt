Fast file pattern matching that works with any codebase size.

Usage:
- pattern is a glob such as "**/*.js" or "src/**/*.ts".
- The path parameter optionally scopes the search to a directory; omit it to use the current workspace directory.
- Returns absolute file paths sorted by modification time, most recently modified first.
- Results are capped at 100; truncated output says so. Tighten the pattern or path instead of paging.

Examples:
- pattern "**/*.test.ts" finds test files at any depth.
- pattern "*.json" with path "/repo/config" finds top-level JSON files in one directory.

Batch multiple speculative patterns as parallel calls in a single message rather than searching one pattern at a time.

When NOT to use:
- Searching file contents — use Grep.
- Exploring an unfamiliar layout — use the list tool.
- Open-ended searches needing multiple rounds of globbing and grepping — use the Task tool instead.
